# UniBot — Sistema Asesor Académico

Proyecto de la Tarea Integradora de Algoritmos y Programación I (Universidad Icesi).
Aplicación de consola en Node.js/TypeScript que simula un sistema RAG restringido
por carrera para atender consultas académicas de estudiantes de primer ingreso.
